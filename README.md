# 🇧🇩 Shahajjo AI (সাহায্য)

**Shahajjo AI** is an indigenous, multi-lingual AI assistant built for Bangladesh. It seamlessly supports native Bengali, Banglish, and English with auto-language detection and real-time Web/Wikipedia search capabilities.

## 🚀 Features
- 🌐 Multi-lingual UI and Language Switcher (Bangla, Banglish, English)
- 📖 Real-time Wikipedia Knowledge Retrieval Engine
- ⚡ Lightweights and suitable for all
